Hệ thống quản lý & hỗ trợ học tập nội bộ Khoa CNTT (HOU). Backend Python (FastAPI), mobile Flutter/RN, web admin React. Chức năng: tra cứu lịch/điểm, thủ tục hành chính một cửa, điểm danh QR (GPS Haversine ≤50m + pitch gyroscope), chat lớp học phần, tin tức.

**Nguồn dữ liệu**: website nội bộ sscfit.hou.edu.vn (user có toàn quyền). Đã chốt kiến trúc: KHÔNG dùng chung DB; xây Provider API read-only hoặc đồng bộ file Excel (giáo vụ upload tập trung) → đổ vào DB nội bộ chuẩn hóa (Anti-Corruption Layer). Khóa định danh ổn định + `updated_at` + soft-delete + upsert idempotent.

**Đã làm (thư mục `db/` trong project)**: `schema.sql` (PostgreSQL) + `build_seed.py` → `seed.sql` cho 3 CTĐT: CN 2022 (126 TC), KS 2022 (150 TC), KS 2019 (141 TC). Mô hình: ctdt → khoi_kien_thuc (lồng nhau) + chuyen_nganh + hoc_phan (danh mục dùng chung) + ctdt_hoc_phan (bảng trung gian vai trò) + quy_tac_tin_chi + dieu_kien_tien_quyet. loai_hp = BAT_BUOC/TU_CHON_DINH_HUONG/TU_CHON_TU_DO.
