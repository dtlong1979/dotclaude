Nền tảng SaaS multi-tenant "tự làm website/landing page đám cưới online" cho thị trường VN. Người dùng đăng nhập → chọn mẫu → nhập thông tin → hệ thống sinh landing page (album, video, guestbook, RSVP, lịch trình+map, QR mừng cưới, đếm ngược...). Editable block 2 chế độ edit/publish. Có subdomain + custom domain.

Đặc tả chi tiết: **Project1/wedding-builder-spec.md** (kiến trúc, data model, block system, editor, domain/SSL, thanh toán, giá, pháp lý, lộ trình 3 giai đoạn).

Phương án PILOT self-hosted: **Project1/wedding-builder-pilot.md** — chốt chạy trọn vẹn trên 1 server, KHÔNG dịch vụ ngoài trừ video nhúng YouTube. Thay thế: Caddy on-demand TLS (thay Cloudflare for SaaS, có ask endpoint /internal/tls-check chống lạm dụng cert), media local + libvips + Caddy file_server (thay R2), VietQR tĩnh thủ công + admin xác nhận (thay SePay/cổng), auth email/mật khẩu (OAuth/SMS để sau), email dùng in-app notification (Postfix deliverability yếu). Docker Compose 1 file: caddy+next+api(FastAPI)+worker+postgres+redis. Cần VPS 4vCPU/8GB + IP tĩnh. Lộ trình 7-8 tuần.
