Mã nguồn Fithou One nằm ở **D:\dev\hou-cntt** (KHÔNG phải C:\Dev). `C:\Dev` chỉ là junction trỏ tới `D:\dev`; junction này có thể tự rời ra (sau reboot) khiến `C:\Dev` thành thư mục rỗng — khi đó cứ dùng đường dẫn `D:\dev\...` thật.

**Khởi động (Windows, PowerShell):**
- PostgreSQL standalone (không phải service), chạy từ `D:\dev\pgsql`, data `D:\dev\pgdata`, listen 5432. psql: `D:\dev\pgsql\bin\psql.exe -U postgres -d hou_cntt -h 127.0.0.1` (mật khẩu PGPASSWORD=postgres; đặt PGCLIENTENCODING=UTF8 + chạy file .sql UTF-8 để tránh lỗi tiếng Việt).
- Backend: `uvicorn app.main:app --host 0.0.0.0 --port 8000` chạy trong `D:\dev\hou-cntt\backend` (port 8000 cho mobile; 8010 cho web admin). KHÔNG có --reload nên phải tự restart sau khi sửa code. API prefix là `/api` (vd `/api/auth/login`, `/api/gv/...`). Login form: POST /api/auth/login body username/password.
- Mobile Flutter: `flutter` ở `C:\flutter\bin\flutter.bat` (không có trên PATH). Build `flutter build apk --debug`; cài lại bằng uninstall+install (chữ ký/INSUFFICIENT_STORAGE nếu install -r). adb ở `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`. Emulator AVD **Pixel_10_Pro** (`%LOCALAPPDATA%\Android\Sdk\emulator\emulator.exe -avd Pixel_10_Pro`). App package `vn.edu.hou.fit.fithouone`; emulator gọi backend qua 10.0.2.2:8000.
